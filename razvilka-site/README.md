# Развилка — карта решений по недвижимости

Одностраничный навигатор: 16 вопросов → тип ситуации, открытые сценарии, план и заявка на разбор.
Чистый HTML/CSS/JS в одном файле, без сборки и зависимостей.

- Файл для публикации: `index.html` (лежит в корне, GitHub Pages отдаёт его по умолчанию).
- `.nojekyll` — чтобы Pages не обрабатывал файлы через Jekyll. Не удалять.

---

## 1. Публикация на GitHub Pages

### Вариант А — через сайт (без терминала)

1. Создайте репозиторий, например `razvilka`. Тип — **Public** (Pages на бесплатном аккаунте работает только в публичных репозиториях).
2. На странице репозитория: **Add file → Upload files**, перетащите `index.html` и `.nojekyll`.
   Файл `.nojekyll` начинается с точки — в проводнике Windows включите показ скрытых файлов или перетащите его вместе с папкой.
3. **Commit changes**.
4. **Settings → Pages → Source: Deploy from a branch**, Branch: `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты появится адрес вида `https://<логин>.github.io/razvilka/`.

### Вариант Б — из терминала

```bash
cd путь/к/razvilka-site
git init
git add .
git commit -m "Развилка: карта решений"
git branch -M main
git remote add origin https://github.com/<логин>/razvilka.git
git push -u origin main
```

Дальше включите Pages в Settings → Pages, как в пункте 4.

### Как обновлять

Правьте файл `C:\Users\Admin\Desktop\index.html`, затем заменяйте им `index.html` в репозитории
(Upload files → перетащить → Commit). Pages пересобирает сайт за 1–2 минуты.
Если изменения не видны — обновите страницу с Ctrl+F5: браузер кэширует старую версию.

## 2. Яндекс.Метрика

Код счётчика в страницу вшит: достаточно вписать номер, скрипт `tag.js` подключится сам.

1. **metrika.yandex.ru → Добавить счётчик.**
   - Название: `Развилка`.
   - Адрес сайта: `<логин>.github.io` (домен без пути и без `https://`; Метрика не принимает `file://`).
   - Вебвизор, карта скроллинга — по желанию.
2. Скопируйте **номер счётчика** (8 цифр).
3. В `index.html` найдите:

   ```js
   analytics: { metrikaId: 0 },
   ```

   и замените на номер:

   ```js
   analytics: { metrikaId: 84302156 },
   ```

4. Закоммитьте файл. Через пару минут откройте сайт и проверьте: **Отчёты → В реальном времени**.

### Цели

Настройки → **Цели** → «JavaScript-событие», идентификаторы строго такие:

| Идентификатор | Когда срабатывает |
|---|---|
| `stage2` | пройдены первые 6 вопросов, показан предварительный тип |
| `result` | построена карта |
| `cta_click` | нажата кнопка «Получить разбор» |
| `lead_submit` | отправлена заявка |
| `share` | карта отправлена второму участнику |

Воронка для наблюдения: визит → `stage2` → `result` → `cta_click` → `lead_submit`.

## 3. Что настраивается в самом файле

Все настройки — один блок `CONFIG` в начале `<script>`:

| Параметр | Что это |
|---|---|
| `lead.endpoint` | адрес приёма заявок (Formspree/webhook). Пусто — протокол копируется в буфер и человек отправляет его в Telegram |
| `lead.telegram` | ваш ник, `Kos_lex` |
| `offer.minutes` | длительность разбора |
| `offer.freeSlots` | сколько первых разборов бесплатно (сейчас 30) |
| `offer.taken` | сколько уже провели. Обновляйте вручную: при 30 страница сама переключится на «по договорённости» |
| `author.*` | имя, город, опыт, кейсы |
| `analytics.metrikaId` | номер счётчика Метрики |

### Проверка перед публикацией

Откройте сайт с `?debug=1` (например `https://<логин>.github.io/razvilka/?debug=1`):

- сверху появится панель с демо-лидами — прогоните все семь, чтобы увидеть разные типы;
- внизу карты будет список «Что заполнить перед публикацией» — он должен быть пустым;
- в блоке отладки видны тип, режим, индекс напряжения и оценка лида A/B/C.

### Про заявки

Пока `lead.endpoint` пустой, заявка — это текст, который человек вставляет вам в личку Telegram.
Когда захотите получать их автоматически: зарегистрируйтесь на formspree.io, создайте форму
и вставьте её адрес в `lead.endpoint` — заявки с типом, оценкой и всеми ответами будут приходить на почту.
